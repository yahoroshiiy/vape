# NOIR VAPE Telegram bot

Бот читает каталог и магазины напрямую из Django API сайта. Пользователь может открыть конкретный товар на вашем сайте и написать администратору прямо в Telegram.

## Переменные окружения

```text
TELEGRAM_BOT_TOKEN=ТОКЕН_ОТ_BOTFATHER
SITE_URL=https://ваш-сайт.vercel.app
TELEGRAM_ADMIN_IDS=ID_АДМИНИСТРАТОРА
```

`TELEGRAM_ADMIN_IDS` — Telegram ID пользователей, которым разрешено отвечать клиентам. Можно указать несколько ID через запятую.

## Как работает поддержка

1. Пользователь пишет боту любое сообщение.
2. Бот отправляет его всем указанным администраторам и показывает имя, username и Telegram ID.
3. Администратор нажимает **Ответить** на пересланное сообщение и пишет ответ.
4. Бот автоматически отправляет этот ответ исходному пользователю.
5. Связка сообщений сохраняется в `support.sqlite3`, поэтому она не пропадает при перезапуске бота.

Поддерживаются обычный текст, фото, видео, документы и другие сообщения, которые Telegram позволяет скопировать.

## Запуск локально

```powershell
cd bot
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
$env:TELEGRAM_BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
$env:SITE_URL="http://127.0.0.1:8000"
$env:TELEGRAM_ADMIN_IDS="ВАШ_ID"
python main.py
```

## Функции

- каталог;
- категории;
- карточки товаров;
- **кнопка «Открыть этот товар на сайте» вместо официальной страницы производителя**;
- магазины;
- связь с администратором через Telegram;
- ссылка на сайт.

Корзины, оплаты и дистанционного заказа никотинсодержащей продукции в боте нет.
